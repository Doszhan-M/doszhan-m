Finsight

Finsight is my own product. I built it from the first idea to the first 1,000 users. It keeps accounts, expenses, debts, loans and analytics in one place for individuals, families and small teams.

The app is local-first. It works with a local SQLite database, and PowerSync syncs the changes with the backend in the background, so the interface never waits for the network. Sensitive fields are encrypted on the device before they leave it, so the server keeps data it cannot read. The backend runs on Django with PostgreSQL, and one codebase ships to web, Android, iOS and Windows.
