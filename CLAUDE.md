# Портфолио Doszhan Mengaliyev

Статический сайт-портфолио: webpack собирает `src/` в `dist/`. Прод — `https://doszhan-m.netlify.app`
(Netlify, настройки сборки — в интерфейсе Netlify, в репозитории их нет). Контент сайта —
на английском.

## Устройство

- HTML собирается из `src/partials/*.html` своим препроцессором `<!--#include file="..." -->`
  (`webpack.config.js`). Попапы проектов — `src/partials/popups/`, открываются через `:target` по хешу.
- Стили — `src/scss/`: токены (цвета, шрифты, радиусы) в `:root` в `main.scss`, общие классы
  `.section`, `.section-head`, `.card`, `.chip`, `.btn`, `.reveal`. Новое — из них, без новых цветов.
- JS — модули в `src/js/`, точка входа `entry.js`. jQuery нет и не возвращать.
- `src/img/` целиком копируется в сборку; в precache service worker — только оболочка
  (список `include` в `webpack.config.js`), остальные картинки кэшируются при показе. Тяжёлое и
  исходники туда не класть; слайды — webp q≈78, ширина ≤ 1600.
- JS и CSS в проде — с хешем в имени (`js/main.<hash>.js`), кэш на Netlify — `src/_headers`.
- Шрифты свои (`src/fonts/`, OFL), `@font-face` — в инлайновом CSS `head.html`. Иконки — не
  Font Awesome kit, а маски из SVG FA в `src/scss/_icons.scss` (новая иконка — по инструкции там). Исходники (фото с EXIF/GPS, SVG обложек) — в `originals/`,
  папка в `.gitignore`.
- Картинка превью для соцсетей — `node scripts/og/render.js` из `scripts/og/og-image.html`.

## Правила работы

- **Не коммитить и не пушить без слова пользователя.** Довести правку, проверить, доложить и
  предложить коммит одной строкой. Пуш в `main` считать выкладкой на прод.
- GitHub Action `profile-summary-cards` сам коммитит в `main` (4 и 19 числа): перед пушем
  `git pull --rebase`.
- Отвечать по-русски. Коммиты — по-английски, `feat:`/`fix:`/`chore:`/`docs:`, тело объясняет «зачем».
- Минимальный diff, без попутных рефакторингов; найденное по дороге — пунктом в отчёте.
  Новые зависимости — только по согласованию.
- Крупная задача (новый раздел, несколько сессий, неясные требования) — сначала план, после
  одобрения спецификация в `specs/` по `specs/TEMPLATE.md`; ход работы и решения — туда же.

## Решения пользователя (не переделывать без его слова)

- Токен Telegram-бота формы лежит в клиентском бандле (`src/js/bot.js` через `DefinePlugin`). Это
  известно; переносить на сервер решено не делать.
- Видео hero (`src/img/prev_video/`, ~22 МБ) не пережимать и не трогать.
- Плашка «Built with Spline» скрыта стилем в shadow DOM (`video_loader.js`); упоминание автора
  модели в подвале — требование лицензии CC BY 4.0, его не убирать.

## Ловушки

- Шрифт OxinWar (hero) не содержит заглавных глифов: текст в верхнем регистре в нём невидим.
- Попапы и прелоадер скрыты/оформлены инлайновым CSS в `src/partials/head.html`. Без этого, пока
  грузится `main.css`, последний попап виден поверх прелоадера (в dev — всегда: там style-loader).
- В dev (`npm run dev`) CSS подключается через JS — мигания при загрузке там не равны проду.
- Прелоадер уходит по готовности шрифтов и hero, но не позже `PRELOADER_MAX_MS` (3.5 с,
  `src/js/index.js`); `window.load` не ждать — он ждёт видео и Spline. Робот проявляется сам,
  когда сцена загрузится. После ухода прелоадера — событие `site:ready`: по нему грузится Метрика
  и регистрируется service worker.
- Закрытые попапы — `display: none` (не `opacity`): иначе их картинки считаются видимыми и
  `loading="lazy"` не работает — +3.7 МБ на старте.

## Как проверять

- `npm run build && npm run check` — браузерная проверка собранного сайта на ПК и телефоне
  (`scripts/browser/check.js`): ошибки JS, прелоадер, меню, прокрутка, попапы, фильтры, ширина.
  Playwright из кэша npx и системный Chrome, новых зависимостей нет. Скриншоты —
  `.claude/scratch/browser/shots/`, смотреть их глазами после визуальных правок.
- `npm run perf` — скорость первого захода на медленном 4G (ПК и телефон): время прелоадера,
  что скачано до его ухода, трафик service worker. Для прода — `node scripts/browser/perf.js <url>`.
  После правок, влияющих на загрузку, — замер до и после.
- Проверять результат, а не исходник. Если проверить не удалось — так и сказать.
